# Fixed-weight intervention contract

## The exact intervention

For layer l, head h, the original head result is `softmax(Q K^T / sqrt(d_head)) V`. Concatenate heads, multiply by W_O, add the incoming residual. A muted head's corresponding concatenation slice is replaced by zero at **every** position before W_O. No model weights change; all later Q/K/V, attention, values, residuals and logits are recomputed. Attention in that same layer remains computed and visible even for a muted head.

No-op exactly matches the native original forward pass on checked cases, including all Q/K/V, attention and concatenations. Muting all heads leaves the input embeddings plus fixed positions at every residual block. The output head still runs. Effects can be nonlinear and non-additive because later attention patterns change. Zero ablation can produce activations outside the training distribution; no mean-ablation, rescue, path-patching or discovered-circuit claim is made.

## Checkpoint and task

Dim 8, heads 2, layers 2, vocab 12 (0-9 numeric tokens, 10 marker, 11 query). Seed 7 initialization; 100 epochs, each 64 fresh samples from the original deterministic dataset with epoch seed 8+epoch; SGD 0.1, global-norm clipping 1.0. Length 8 training and evaluation. Initialization reference has identical architecture and seed before SGD. This is not a competitive trained baseline.

The original held-out dataset is 128 examples, seed 100007. Every example is evaluated under every subset for both checkpoints. The 11 interactive cases are eight fixed-seed samples from seed 700011, then declared repeated-key and edge-marker structures. They are not selected by outcome. The UI can inspect valid user-edited sequences of length 4-24, outside-training lengths included without claiming generalization.

## Matched input changes

Each case uses all ten possible numeric replacements at the position immediately after the marker, including the original token as a no-op. The target changes with that token. Each filler position gets one deterministic replacement `(token + 1) % 10`, with the original recalled-key target unchanged. Marker and final query stay fixed. All heads remain kept. These are input counterfactuals, not activation patches, and a changed output alone does not identify a circuit.

## Numerical loss repair

Originally both `cross_entropy` and `loss_and_grads` returned `-log(max(p_target, 1e-12))`, but the latter returned `softmax - one_hot` even when clipping made the loss constant. Stable log-sum-exp now returns `max(logits) - target_logit + log(sum(exp(logits - max)))`. An extreme target can have finite large loss even when its probability underflows to zero. For logits `[1000,-1000]` and target 1 this is 2000, not 27.631. New extreme bias finite differences verify the repaired loss against its gradients. The optimizer, forward computation, all 46 original tests' source files and original demo are not altered.

## Reproduction and boundaries

Complete serialized weights, original held-out inputs, 100 training losses, all subset aggregates and fixture pins are generated by `scripts/build_workbench.py`. Complete intermediate inference is computed independently, not stored as the browser's answer. `scripts/verify_regeneration.py` retrains/recomputes everything and compares at normalized 1e-12 tolerance, preserving file bytes. Python/JS full tensors use normalized 1e-10. No measured training speed, benchmark latency, GPU, hardware-memory, or cross-runtime bitwise equivalence claim.

Strict checkpoint import rejects extra/missing groups, wrong shapes, bool dimensions/weights, nonfinite values and out-of-range architecture. CLI rejects duplicate JSON keys, nonfinite constants and files above 100000 UTF-8 bytes, with exit 2 and no partial output. Parameter magnitudes are capped at 10000 in the workbench interchange format; this is not a general safe untrusted-model execution sandbox. The UI uses only its two packaged checkpoints, not arbitrary model upload.

The original source hash manifest is `attnlens/data/original-hashes.json` at commit `48ae1f6c50a4ae7a1909105d09cfaa26d09567fe`. Original tests/trainer/data/demo remain unchanged. The only behavioral modification to the original implementation is stable loss reporting; added intervention code sits separately.

## Sources and prior work

1. Vaswani et al., *Attention Is All You Need* (2017). [Primary paper](https://arxiv.org/abs/1706.03762). Scaled dot-product attention, head concatenation/output projection, positional encoding and residual architecture. This tiny attention-only model is not the full paper architecture.
2. Jain and Wallace, *Attention is not Explanation* (2019). [ACL Anthology](https://aclanthology.org/N19-1357/). Attention-weight/output disagreement motivates distinguishing maps from prediction effects. Their experiments are not reproduced here.
3. Wiegreffe and Pinter, *Attention is not not Explanation* (2019). [ACL Anthology](https://aclanthology.org/D19-1002/). The debate depends on definitions and experimental controls. The workbench does not claim the debate is settled.
4. Elhage et al., *A Mathematical Framework for Transformer Circuits* (2021). [Primary research article](https://transformer-circuits.pub/2021/framework/). QK versus OV pathways, residual contributions and attention-head composition. This model does not establish their circuits.
5. Olsson et al., *In-context Learning and Induction Heads* (2022). [Primary research article](https://transformer-circuits.pub/2022/in-context-learning-and-induction-heads/index.html). Induction-head and ablation context; their trained models and benchmark findings are not this repository's results.
6. SciPy, *logsumexp*. [Official numerical reference](https://docs.scipy.org/doc/scipy/reference/generated/scipy.special.logsumexp.html). Stable log-sum-exp formulation. SciPy is not a dependency; implementation is pure Python/JavaScript.

All sources were consulted for implementation/method boundaries. The native code, export format, independent browser engine, inspection UI and test harness are educational implementation work, not a new attention architecture or scientific discovery.
